Луи

Настройки Луи

Чтобы Луи стал умным и видел камеру, ему нужен бесплатный ключ Google Gemini.

  1. Открой aistudio.google.com/apikey и войди в Google-аккаунт.
  2. Нажми «Create API key», затем скопируй ключ.
  3. Вставь его сюда и нажми «Сохранить».

Ключ хранится только на этом телефоне и отправляется только в Google. Никому его не показывай. На бесплатном тарифе Google может использовать переписку для улучшения своих моделей.


      
Голос

      
      
      
      
      
Самый живой голос получится, если скачать улучшенный русский голос в iPhone: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → например «Милена (улучшенный)» или «Юрий (улучшенный)». Потом закрой и снова открой Луи и выбери этот голос здесь.
